# Eden Soundworkz Technologies
## MSP PowerShell Automation Lab

A hands-on PowerShell automation portfolio focused on IT support,
systems administration, network troubleshooting, Active Directory
concepts, and Microsoft Entra ID.

## Technologies

- PowerShell 7
- Microsoft Graph PowerShell SDK
- Microsoft Entra ID
- Active Directory concepts
- Git and GitHub
- macOS

## Completed Labs

| Lab | Project | Description |
|-----|---------|-------------|
| 01 | System Inventory | Collects system information and exports CSV reports |
| 02 | Network Diagnostics | Tests connectivity and DNS resolution |
| 03 | Employee Onboarding | Simulates username creation and group assignments |
| 04 | Help Desk Reporting | Analyzes tickets and technician workloads |
| 05 | Active Directory Simulation | Simulates organizational units and user provisioning |
| 06 | Microsoft Entra ID Audit | Retrieves identity information using Microsoft Graph |

## PowerShell Scripts

### NetworkDiagnostics.ps1
Automates network troubleshooting and generates connectivity reports.

### EmployeeOnboarding.ps1
Simulates employee onboarding, username generation,
department mapping, and duplicate detection.

### HelpDeskReport.ps1
Processes help desk tickets and generates operational reports.

### ADUserProvisioning.ps1
Simulates Active Directory provisioning and validates
employee account information.

### EntraIdentityAudit.ps1
Uses Microsoft Graph to retrieve the authenticated user's
profile and generate a cloud identity audit report.

## Important Notes

- Active Directory provisioning is simulated.
- No production Active Directory accounts are created.
- Microsoft Graph operations are read-only.
- Sample employee and help desk records are fictional.
- Real identity reports and credentials are excluded.
