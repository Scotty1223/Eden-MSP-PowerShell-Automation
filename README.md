# Eden Soundworkz Technologies
## MSP PowerShell Automation Lab

A hands-on IT automation portfolio demonstrating PowerShell scripting,
network troubleshooting, employee onboarding, help desk reporting,
Active Directory simulations, and Microsoft Entra ID integration.

### Technologies
- PowerShell 7
- Microsoft Graph PowerShell SDK
- Microsoft Entra ID
- Active Directory concepts
- macOS
- Git and GitHub

### Completed Labs
1. System Inventory Automation
2. Network Diagnostics
3. Employee Onboarding Simulation
4. Help Desk Reporting
5. Active Directory Provisioning Simulation
6. Microsoft Entra ID Identity Audit

### Project Highlights
- Automated network troubleshooting and reporting
- Employee username generation and duplicate detection
- Help desk ticket analysis
- Simulated Active Directory provisioning workflows
- Live, read-only Microsoft Graph identity reporting
- CSV-based reporting and automation
